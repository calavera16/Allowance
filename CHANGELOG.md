# Changelog

## 0.3.4

### Monitoring

- Codex and Claude Code quota windows, remaining percentages, and reset countdowns.
- Codex credit balances when reported by the CLI.
- Live and last-known readings, with stale data excluded from current totals,
  alerts, new history observations, and planning.
- Configurable refresh intervals, a compact tray popup, usage notifications,
  reset reminders, spike alerts, and quiet hours.

### Planning and personalization

- Overview, Plan, Activity, and Companion views.
- Named coding sessions, saved receipts, working-day budgets, an allowance
  reserve, usage forecasts, and a combined reset timeline.
- Local charts, a 90-day activity heatmap, and separate profiles.
- An optional desktop overlay with built-in companions and custom GIFs,
  animation controls, and keyboard movement and resizing.
- High contrast, reduced motion, and optional launch at Windows sign-in.

### Data and reliability

- JSON backup and restore, including selected companion GIFs, and CSV export.
- Saved-data recovery that preserves damaged originals and reports storage issues.
- Profile validation and safeguards for active coding sessions.
- Session controls that remain reliable during refreshes and recoverable export errors.
- Confirmed Claude hook installation and removal that preserve unrelated settings.
- Installer cleanup of the owned Claude hook, redacted diagnostics, and bounded
  collection and storage.

### Distribution

- Windows x64 installer and portable downloads.
- Unsigned executables and manual updates for this version.
